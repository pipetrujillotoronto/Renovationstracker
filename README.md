
  # Renovation project tracker (Portfolio Project)

  Prototype in Figma: If you have ever had a renovation or construction project at your home, it is quite difficult to follow the expenses on raw materials and contractor costs. The idea behind this APP is to be able to follow the expenses by contractors, with the bills and pictures of the progress, and give approvals before it happens. Keep your project on track and on budget.

  This is a code bundle for the Renovation project tracker. The original project is available at https://www.figma.com/design/azGfL5EmjPe22yZFr6z294/Renovation-project-tracker.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
